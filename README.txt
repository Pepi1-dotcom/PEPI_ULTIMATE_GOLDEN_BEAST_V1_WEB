PEPI ULTIMATE GOLDEN BEAST V1 - WEB EDITION

This is a self-contained browser app. Open index.html in a browser to run it.

SIMULATION ONLY:
- No broker connection
- No MT5 connection
- No real trade execution
- Prices and signals are simulated

WEB HOSTING:
Upload index.html to any static web host. For GitHub Pages, create a repository,
put index.html in the root, enable Pages, and select the main branch/root folder.

The project is intentionally dependency-free so it can be hosted as a static site.
